# Compress Video — support and privacy

Public support, privacy and data-deletion pages for Android and iOS.
GitHub Pages serves the root of `main` at https://wrocketdev.github.io/video-compressor/.

The current policy describes version 1.8.0 and later (no ads or purchases),
local video processing, and PostHog technical analytics. The previous Android
policy is preserved in the two `*-android-1.7.html` pages for older installations.

Support: `support.html` (English), `assistance.html` (French).
Privacy: `privacy-policy.html`, `politique-confidentialite.html`.
Deletion: `data-deletion.html`, `suppression-donnees.html`.

Keep these pages consistent with the shipped application and its store disclosures.
